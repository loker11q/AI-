# AI 智能摄像头系统

基于地平线 RDK X5 的 AI 视觉检测与远程监控系统，实现车辆实时检测、自动抓拍、云端上报及远程控制。
链接：https://pan.quark.cn/s/6a4266dc9685?pwd=Lsfa
提取码：Lsfa

---

## 项目概述

| 项目角色 | 说明 |
|---------|------|
| 硬件平台 | 地平线 RDK X5（旭日X5）+ BPU AI加速器 |
| 摄像头 | 安佳网络摄像头 × 2（以太网 + WiFi）|
| 电机控制 | 串口步进电机驱动板，控制云台与镜头焦距 |
| AI模型 | YOLOv5s，BPU 硬件加速推理 |
| 通信协议 | MQTT（远程控制）、RTSP（视频流）、HTTP（数据上报）|

---

## 参与内容

- **摄像头外壳 3D 设计**：完成摄像头外壳的结构设计与原型制作
- **硬件联调**：负责安佳网络摄像头与 RDK X5 开发板的对接调试，包括 RTSP 视频流配置、串口通信调试
- **安装部署**：现场设备安装、网络布线、系统联调测试

---

## 技术栈

硬件 / RDK X5、BPU、安佳IP摄像头、串口步进电机、GPIO

AI与视觉 / YOLOv5s、OpenCV、BPU硬件加速、ROI区域检测

通信 / MQTT、RTSP、RTMP、HTTP API、串口协议

云端 / 对象存储、设备心跳与数据上报、远程配置

前端 / MQTT.js Web控制面板

---

## 功能特性

- **AI 车辆检测**：YOLOv5s 模型实时检测，BPU 硬件加速
- **智能抓拍**：车辆进入 ROI 区域后自动拍照，60秒冷却防重复
- **远程控制**：通过 MQTT 远程控制云台转动、镜头调焦、IRCUT 切换
- **视频推流**：支持 RTMP 推流，实时查看摄像头画面
- **云端存储**：抓拍图片上传云端，生成可访问链接
- **补光灯控制**：GPIO 控制，60秒自动关闭防过热
- **远程更新**：支持通过网络更新设备端代码
- **Web 控制面板**：浏览器端可视化控制界面

---

## 系统架构

```
摄像头画面 → YOLOv5 检测 → 车辆筛选 → ROI 判断
    → 拍照 → 云端上传 → 服务器上报 → 远程通知
```
